# Research pins

This directory preserves open research questions discovered while promoting real Document semantics into VSlices Docs Standard.

A pin is not normative vocabulary by itself.

Pins exist to preserve tensions that recur across Document types without forcing a premature abstraction into the machine-consumable definitions.

During each Document review:

1. inspect existing pins before concluding the semantic graph;
2. update a pin when the new Document provides additional evidence, counterexamples, distinctions, or questions;
3. create a new pin when a distinct recurring research question appears;
4. keep Document-specific unresolved modeling questions beside that Document when they do not yet appear transversal;
5. promote or reject a pin only after enough evidence supports a resolution;
6. preserve the reconstructible path when a pin is resolved.

## Current working distinctions

### Nexus / composition

Research around:

- shared representations;
- partial documentary views;
- semantic granularity;
- recursive decomposition;
- composition of several Documents around the same target;
- possible recursive composition of Nexus artifacts.

### Diagnostic / tension

Research around:

- friction;
- ambiguity;
- contradiction;
- fragility;
- risk;
- problematic coupling;
- whether a difficult condition belongs intrinsically to a Document or constitutes diagnosis of that knowledge.

### Drift

Research around:

- validity;
- degradation;
- obsolescence;
- divergence between represented or expected knowledge and current or observed reality.

Consistency is the next explicit pressure case for the Drift hypothesis.

## Rule of promotion

The machine-consumable Document definitions express semantics that are currently promoted.

Pins preserve uncertainty that still deserves investigation.

A recurring pattern is evidence, not automatic authority.
